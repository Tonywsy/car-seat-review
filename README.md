# car-seat-review ｜ 儿童安全座椅大横评

千元档 vs 旗舰档，13 款横评可视化（3C / i-Size / ADAC 数据底座）

在线地址：https://tonywsy.github.io/car-seat-review/

## ⚠️ 先说清楚：本页是什么、不是什么

本页为**开源民间信息汇总，非第三方检测报告，无商业带货**；所有参数采集自品牌官网与电商详情页，**无实物拆机、无碰撞实验**，商家存在参数虚标的可能性。表格仅供**初筛**——最终下单务必以**座椅本体刻印的 i-Size / E-mark 标签与 3C 证书原件**为准，本页不作为购买唯一依据。

- 参数来源：品牌官网 / 电商详情页 / 公开行业研报 / ADAC、Stiftung Warentest 公开报道（采集 2026-08）
- 价格口径：电商常卖参考价，随促销波动，仅供参考
- 13 款产品均验证为京东/天猫在售、有独立商品页与评论数

## 建议阅读路径

先读科普避坑章节（段位之争 / 装车避坑）→ 确定预算 + 目标年龄段 → 用表格筛出 2-3 个候选 → 线下试坐 + 实车装车 + 核对实物标签再下单。
