> 本页所有数据来自品牌官网 / 电商公开详情页（采集 2026-08），**无拆机、无碰撞实测，无法识别参数虚标**；评分（含 s12「葵爸主观推荐榜」）为基于公开宣传配置的**纸面配置得分**，不是真实碰撞性能，**仅用于初筛候选，不能直接当作安全高低排名**。最终务必核对座椅本体刻印标签、条件允许尽量线下试装试坐。

## 这是什么

对市售 12 款主流儿童安全座椅，按价格三档（¥1000-2000 / ¥2000-3000 / ¥3000+）做的横向对比：认证解读、硬参数表、元/年成本、装车避坑，以及一份带权重的主观推荐榜。定位是「**帮你筛掉明显配置短板的初筛工具**」，不是碰撞安全测评，也不是排行榜。

## 阅读路径（建议顺序）

1. 先读 02 认证科普 + 03 段位之争 + 10 装车避坑，建立基本判断；
2. 定预算档 + 目标年龄段，用 05 筛选 / 09 比价表筛出 2-3 款；
3. 线下试坐（看实际躺角、座舱宽度、肩带位置）+ 实车装车验证接口与地板凸起 + 核对本体标签与 3C 证书，再下单。

## 重要边界（务必读）

- **纸面配置 ≠ 碰撞实测**：分数来自厂商宣传，无法识别虚标；这是本页最根本的局限。
- **认证是准入门槛不是性能排名**：3C 是国标底线，i-Size(R129) 是更严欧标过关线，都**不等于碰撞性能优秀**。
- **ADAC 成绩是欧版样品送测**，国行版本零部件可能调整、无独立公开报告；无 ADAC ≠ 不安全。
- **安装防错比椅子本身更关键**：真实误用率高达 60-80%，错误安装 = 裸奔。
- **0-12 全龄款结构上有妥协**，新生儿阶段防护冗余上限低于 0-4 专龄款；且壳体出厂 6-8 年建议更换，极少真正用满标称年限。
